Senpai — an H-Slice mod

INSTALL
  1. Put this "senpai" folder inside  h-slice/mods/
  2. Open  h-slice/engineassets/mods.js  and add this line:
       HSLICE.load('mods/senpai/mod.js');
  3. Open index.html. Senpai is in Freeplay.
