Stress — an H-Slice mod

INSTALL
  1. Put this "stress" folder inside  h-slice/mods/
  2. Open  h-slice/engineassets/mods.js  and add this line:
       HSLICE.load('mods/stress/mod.js');
  3. Open index.html. Stress is in Freeplay.
