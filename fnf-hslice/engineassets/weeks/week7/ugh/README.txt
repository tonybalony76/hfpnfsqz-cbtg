Ugh — an H-Slice mod

INSTALL
  1. Put this "ugh" folder inside  h-slice/mods/
  2. Open  h-slice/engineassets/mods.js  and add this line:
       HSLICE.load('mods/ugh/mod.js');
  3. Open index.html. Ugh is in Freeplay.
