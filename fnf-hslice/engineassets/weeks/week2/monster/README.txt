Monster — an H-Slice mod

INSTALL
  1. Put this "monster" folder inside  h-slice/mods/
  2. Open  h-slice/engineassets/mods.js  and add this line:
       HSLICE.load('mods/monster/mod.js');
  3. Open index.html. Monster is in Freeplay.
