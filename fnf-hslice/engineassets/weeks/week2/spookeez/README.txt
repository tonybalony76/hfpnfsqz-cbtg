Spookeez — an H-Slice mod

INSTALL
  1. Put this "spookeez" folder inside  h-slice/mods/
  2. Open  h-slice/engineassets/mods.js  and add this line:
       HSLICE.load('mods/spookeez/mod.js');
  3. Open index.html. Spookeez is in Freeplay.
