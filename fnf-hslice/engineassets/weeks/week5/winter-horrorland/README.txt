Winter Horrorland — an H-Slice mod

INSTALL
  1. Put this "winter-horrorland" folder inside  h-slice/mods/
  2. Open  h-slice/engineassets/mods.js  and add this line:
       HSLICE.load('mods/winter-horrorland/mod.js');
  3. Open index.html. Winter Horrorland is in Freeplay.
