Cocoa — an H-Slice mod

INSTALL
  1. Put this "cocoa" folder inside  h-slice/mods/
  2. Open  h-slice/engineassets/mods.js  and add this line:
       HSLICE.load('mods/cocoa/mod.js');
  3. Open index.html. Cocoa is in Freeplay.
