Blammed — an H-Slice mod

INSTALL
  1. Put this "blammed" folder inside  h-slice/mods/
  2. Open  h-slice/engineassets/mods.js  and add this line:
       HSLICE.load('mods/blammed/mod.js');
  3. Open index.html. Blammed is in Freeplay.
