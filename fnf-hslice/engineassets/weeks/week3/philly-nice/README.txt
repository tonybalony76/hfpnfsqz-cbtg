Philly Nice — an H-Slice mod

INSTALL
  1. Put this "philly-nice" folder inside  h-slice/mods/
  2. Open  h-slice/engineassets/mods.js  and add this line:
       HSLICE.load('mods/philly-nice/mod.js');
  3. Open index.html. Philly Nice is in Freeplay.
