Pico — an H-Slice mod

INSTALL
  1. Put this "pico" folder inside  h-slice/mods/
  2. Open  h-slice/engineassets/mods.js  and add this line:
       HSLICE.load('mods/pico/mod.js');
  3. Open index.html. Pico is in Freeplay.
