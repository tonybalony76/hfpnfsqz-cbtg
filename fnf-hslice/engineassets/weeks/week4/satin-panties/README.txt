Satin Panties — an H-Slice mod

INSTALL
  1. Put this "satin-panties" folder inside  h-slice/mods/
  2. Open  h-slice/engineassets/mods.js  and add this line:
       HSLICE.load('mods/satin-panties/mod.js');
  3. Open index.html. Satin Panties is in Freeplay.
