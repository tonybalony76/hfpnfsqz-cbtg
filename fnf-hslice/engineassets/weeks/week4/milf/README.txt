M.I.L.F — an H-Slice mod

INSTALL
  1. Put this "milf" folder inside  h-slice/mods/
  2. Open  h-slice/engineassets/mods.js  and add this line:
       HSLICE.load('mods/milf/mod.js');
  3. Open index.html. M.I.L.F is in Freeplay.
