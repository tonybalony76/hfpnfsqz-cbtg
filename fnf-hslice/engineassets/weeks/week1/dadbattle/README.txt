DadBattle — an H-Slice mod

INSTALL
  1. Put this "dadbattle" folder inside  h-slice/mods/
  2. Open  h-slice/engineassets/mods.js  and add this line:
       HSLICE.load('mods/dadbattle/mod.js');
  3. Open index.html. DadBattle is in Freeplay.
