Roses — an H-Slice mod

INSTALL
  1. Put this "roses" folder inside  h-slice/mods/
  2. Open  h-slice/engineassets/mods.js  and add this line:
       HSLICE.load('mods/roses/mod.js');
  3. Open index.html. Roses is in Freeplay.
