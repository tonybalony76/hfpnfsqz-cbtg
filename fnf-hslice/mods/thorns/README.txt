Thorns — an H-Slice mod

INSTALL
  1. Put this "thorns" folder inside  h-slice/mods/
  2. Open  h-slice/engineassets/mods.js  and add this line:
       HSLICE.load('mods/thorns/mod.js');
  3. Open index.html. Thorns is in Freeplay.
